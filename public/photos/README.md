# Site photos

Drop a licensed or real Atin photo here to replace a stock image, named after its slot:

| File | Where it shows |
|---|---|
| `hero.jpg` | Home page hero (subject should sit in the right half) |
| `chemist-counter.jpg` | Home "About" block, About page, New additions banner |
| `warehouse.jpg`, `team.jpg`, `lab-quality.jpg`, `hospital-corridor.jpg`, `contact.jpg`, `blog-1.jpg` … `blog-3.jpg` | Other page banners |
| `tablets-capsules.jpg` … `eye-ear-nasal.jpg` | Segment cards and range banners (or upload these in the admin Ranges page) |

`.jpg`, `.jpeg`, `.png` and `.webp` are accepted. Keep files under ~2500 px wide; the site resizes them on request.
The full slot list is in `lib/site/photos.ts`.
